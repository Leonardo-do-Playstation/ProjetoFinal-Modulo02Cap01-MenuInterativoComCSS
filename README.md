📑 Menu Interativo com CSS

Projeto web que implementa um menu de navegação interativo utilizando apenas HTML e CSS.

O objetivo do projeto é demonstrar como criar menus dinâmicos e responsivos sem utilizar JavaScript, explorando recursos de estilização e interação do CSS.

🚀 Tecnologias Utilizadas

HTML5

CSS3

📌 Funcionalidades

✔ Menu de navegação estilizado
✔ Interações visuais com hover
✔ Organização semântica da estrutura HTML
✔ Estilização com CSS moderno

⚙️ Como Executar o Projeto

1️⃣ Clone o repositório

git clone https://github.com/Leonardo-do-Playstation/ProjetoFinal-Modulo02Cap01-MenuInterativoComCSS.git

2️⃣ Entre na pasta do projeto

cd ProjetoFinal-Modulo02Cap01-MenuInterativoComCSS

3️⃣ Abra o arquivo index.html no navegador

Ou utilize uma extensão como Live Server no VS Code.

 ├── index.html
 ├── style.css

Este projeto foi desenvolvido com foco em praticar:
